# Build a Career and University Major Selection Advisor Web Application in Azerbaijani

Build a career and university major selection advisor web application in Azerbaijani.

## Pages

1. **Landing Page:** A headline, a short description, and a “Start the Test” button.

2. **Interest Questionnaire:** 12 questions, each rated on a scale of 1–5. Display one question at a time, with a progress bar at the top. At the end, include a “Show Results” button.

3. **Results Page:** Display cards for the top 3 recommended university majors. Each card should include the major's name, compatibility percentage, an explanation of why it matches the student’s interests, and potential career paths.

4. **AI Chat Panel:** Students can type questions such as “What jobs could I get if I study this major?” The AI's response should appear in the chat.

## Design

Use a modern blue-green color palette, a mobile-responsive layout, and Azerbaijani for all user-facing text.

For now, use mock data for the results.
