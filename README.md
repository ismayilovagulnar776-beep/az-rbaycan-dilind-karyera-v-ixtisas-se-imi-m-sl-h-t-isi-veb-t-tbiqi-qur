# Azərbaycan dilində karyera və ixtisas seçimi məsləhətçisi veb tətbiqi qur

Azərbaycan dilində karyera və ixtisas seçimi məsləhətçisi veb tətbiqi qur.

Səhifələr:

1. Giriş səhifəsi: başlıq, qısa izah, "Testə başla" düyməsi

2. Maraq anketi: 12 sual, hər biri 1-5 şkala (bir-bir göstər, yuxarıda irəliləyiş xətti). Sonda "Nəticəni göstər" düyməsi

3. Nəticə səhifəsi: top 3 ixtisas kartı (ixtisasın adı, uyğunluq faizi, niyə uyğundur, mümkün peşələr)

4. AI çat paneli: şagird "Bu ixtisası oxusam nə iş tapa bilərəm?" kimi sual yazır, cavab çatda görünür

Dizayn: müasir, mavi-yaşıl rəng palitrası, mobil uyğun, bütün mətnlər Azərbaycan dilində.

Hələlik nəticələr üçün saxta (mock) məlumat istifadə et.
